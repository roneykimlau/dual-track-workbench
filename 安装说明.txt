双轨工作台 · iPhone / PWA 安装与使用说明
================================================

一、当前目录文件
----------------
index.html              主应用（由双轨工作台 v20 改造）
manifest.webmanifest    PWA 清单（名称、图标、主题色、启动方式）
sw.js                   Service Worker（离线缓存壳）
icons/                  应用图标（192/512/Apple Touch）
make_icons.py           图标生成脚本（标准库，可重新生成）


二、如何在 iPhone 上安装为 App
-------------------------------
iOS Safari 要求 PWA 必须通过 HTTPS 才能启用「添加到主屏幕」后的
独立 App 体验（无地址栏、可离线）。本地 Wi-Fi 同网段的 HTTP 地址
只能作为网页预览，无法成为完整 PWA。

推荐部署方式（任选其一）：
1. GitHub Pages（本应用已部署）：https://roneykimlau.github.io/dual-track-workbench/
2. Cloudflare Pages / Vercel / Netlify：直接拖拽本文件夹部署。
3. 自己的服务器 / NAS：通过 HTTPS 发布本文件夹。

本应用已部署在 GitHub Pages，线上地址：https://roneykimlau.github.io/dual-track-workbench/
仓库：roneykimlau/dual-track-workbench（公开）。更新代码后 push 到 main 分支即自动重新构建。

部署后，用 iPhone Safari 打开 HTTPS 地址：
• 点击底部分享按钮「↑」
• 选择「添加到主屏幕」
• 桌面即出现「双轨工作台」图标，点击以独立 App 形式打开


三、数据存储说明
----------------
• 所有数据仍保存在本机浏览器 localStorage（前缀 wb_dualwork_）。
• 清除 Safari 数据或卸载主屏幕图标会丢失数据。
• 请定期在应用内点「导出」备份 JSON；重装后可用「导入」恢复。


四、定期更新机制
----------------
• 打开「更新中心」（顶部「更新」按钮）可设置每个内容模块的更新频率：
  行业动态、技术追踪、技能提升、客户动态、采购计划、我方可提供产品。
• 默认：客户动态/采购计划/我方产品「每天」；行业/技术「每周」；技能「每月」。
• 开启「自动更新过期模块」后，应用启动或从后台切回时会自动刷新过期模块。
• 关闭自动更新时，首页会显示「N 个模块内容需要更新」横幅，可手动一键更新。
• 更新动作只刷新「示例/派生内容」，你手动添加的条目始终保留。


五、本地预览（电脑浏览器）
--------------------------
在本目录运行：
    python -m http.server 8765
然后电脑浏览器打开 http://localhost:8765/index.html

如需让同 Wi-Fi 的 iPhone 访问电脑预览：
    python -m http.server 0.0.0.0:8765
手机 Safari 访问 http://<电脑局域网IP>:8765/index.html
（注意：HTTP 预览不能实现完整 PWA 离线能力。）


六、离线能力
------------
首次通过 HTTPS 打开后，Service Worker 会缓存核心文件。
此后在弱网/离线环境下仍可打开应用并查看已有数据；
新增/编辑/删除等写入操作依赖浏览器本地存储，不受网络影响。
